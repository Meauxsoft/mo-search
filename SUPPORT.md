# Support

Use the [Mo-Search issue tracker](https://github.com/Meauxsoft/mo-search/issues)
for reproducible search, indexing, viewer, installer, documentation, and
general Mo-Search bugs or feature requests.

MoContext MCP clients, retrieval tools, context memory, and MoContext UI
reports belong in the
[MoContext issue tracker](https://github.com/Meauxsoft/mocontext/issues).

Before filing an issue:

1. Install the latest public Mo-Search release.
2. Search existing issues.
3. Reproduce the problem with the smallest safe example.

Include the Mo-Search version, Windows version, expected behavior, actual
behavior, and concise reproduction steps.

GitHub issues are public. Redact usernames, personal paths, file contents,
search queries, license details, tokens, and other sensitive information. For
private or licensing questions, email
[Questions@meauxsoft.com](mailto:Questions@meauxsoft.com).

Suspected vulnerabilities follow [SECURITY.md](SECURITY.md), not the public
issue tracker.
